# Baby Deliveries Tracker

Track the babies you've delivered as a nurse. Record each baby's name, gender, weight, and route of delivery.

## Features

- **Stats dashboard** at the top showing total deliveries, boy/girl counts, vaginal/C-section counts, and biggest/smallest weights
- **Record deliveries** with name, gender, weight (lbs/oz), and route (vaginal or C-section)
- **Persistent storage** via Google Drive (sign in to save your data)
- **Delete entries** by tapping the X on any delivery

## How to Run

This is a static HTML app — no build step needed. Open `index.html` in a browser or access it via GitHub Pages:

**https://sethjones348.github.io/sierra-apps/apps/baby-deliveries-tracker/**
